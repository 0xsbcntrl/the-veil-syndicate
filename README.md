# The Veil Syndicate

The Veil Syndicate is a reserve protocol being designed for Robinhood Chain. Its ecosystem combines `$VSYNC`, a fixed collection of 2,100 programmable Cipher NFTs, and an individually accounted reserve in ZEC.

Holders burn `$VSYNC` to activate a Veiled NFT, progress through capped ranks, and access protocol functionality. The core financial primitive, **The Window**, lets an active Cipher access part of its own ZEC cage without selling or permanently redeeming the NFT. The advance is denominated and secured in ZEC, requires no market-price oracle, and has no price-based liquidation.

## The Warden

**The Warden is the planned AI agent for The Veil Syndicate ecosystem.**

It will help Cipher owners monitor their ZEC cages, simulate Window scenarios, understand risk, and manage approved actions through limited and verifiable on-chain mandates. Protocol contracts will continue to enforce reserve accounting, spending limits, settlement, and redemption.

The execution-capable agent will be created once the ZEC reserve reaches a sufficient value to make its automation economically useful. That threshold will be defined from reserve liquidity, Window demand, and safe utilization limits. This sequencing ensures The Warden manages meaningful on-chain value and solves a real coordination problem inside the ecosystem.

```text
The Veil Syndicate establishes the reserve and The Window
                              ↓
The ZEC reserve reaches sufficient scale
                              ↓
The Warden begins managing bounded Window mandates
```

## Current Stage

The project is currently in concept, economic-design, and architecture validation. Reserve thresholds, final `$VSYNC` parameters, ZEC settlement, and agent permissions remain subject to simulation, security review, and legal analysis.

This repository is being presented to the **Orbio AI Agent Contest** as the foundation for a reserve-native agent designed for the Robinhood Chain builder ecosystem.
